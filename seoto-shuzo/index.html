瀬音酒造　仕込み帖

米が酒になるまで、
およそ四十八日。

蔵では、毎朝、醪の温度を帳面に書きます。この頁の左の線は、その記録をなぞったものです。下へ進むほど、日が進みます。

蔵の一日は、下の表のとおりです。

蔵の一日をぜんぶ見る
  1. 0:00〜4:00夜の番麹室と酛のタンクを、交代で見回ります。温度が上がりすぎていないか、手で確かめます。
  2. 4:00〜5:00蒸しの支度釜に火を入れて、湯をわかします。
  3. 5:00〜6:00朝の測り醪と酛のタンクの温度を測って、帳面に書きます。
  4. 6:00〜8:00蒸し甑（こしき）で米を蒸します。湯気で、蔵の中が白くなります。
  5. 8:00〜9:00朝ごはん蔵のみんなで食べます。
  6. 9:00〜11:00麹室と酛の手入れ蒸した米を冷まして麹室へ運びます。酛のタンクをかき混ぜます。
  7. 11:00〜12:00洗米・浸漬明日の米を洗って、ストップウォッチで測りながら水に浸けます。
  8. 12:00〜13:00昼ごはん午後の仕事の前に、ゆっくり休みます。
  9. 13:00〜15:00タンクの作業仕込みの日は米・麹・水を足します。搾りの日は、醪の袋を積みます。
  10. 15:00〜17:00道具の掃除桶・布・ホースを洗って、乾かします。蔵はいつも清潔に。
  11. 17:00〜18:00夕方の測りもう一度、すべてのタンクの温度を測って、帳面に書きます。
  12. 18:00〜19:00夕ごはん一日の仕事を、みんなで振り返ります。
  13. 19:00〜22:00帳面と段取り今日の記録をまとめて、明日の作業を決めます。
  14. 22:00〜24:00夜の番交代で見回りの番に入ります。

あなたの端末の時刻に合わせた、サンプルの蔵の一日です。実在の蔵の予定ではありません。時刻は、この端末の中だけで使っていて、どこにも送りません。

いま何日目で、何の仕事をしているかは、画面の左（スマホは、画面の下の帯）に出ています。迷ったら、そこの目次か、上の蔵の名前から、いつでも戻れます。

1日目洗米・浸漬

米を洗って表面の糠を流し、水を吸わせます。吸わせすぎると、蒸しあがりが柔らかくなりすぎます。だから、ここだけはストップウォッチで、秒を測ります。

水の温度
約8℃
吸わせる時間
数分〜（秒単位で調整）

2日目蒸し

甑（こしき）で、約1時間蒸します。目指すのは、外は固く、中は柔らかい米。蒸しあがった米は、手で持てる温度まで冷まして、麹室へ運びます。

蒸す時間
約60分
冷ましたあと
約30℃

3〜4日目麹

蒸した米に麹菌をふり、約48時間かけて育てます。麹は自分で熱を出して、温度が40℃近くまで上がります。2〜3時間おきに棚を見に行き、手で混ぜて、熱を逃がします。

育てる時間
約48時間
温度
30〜40℃

米1粒から、麹菌まで

麹が働いているのは、米の粒の、そのまた中です。下へ進むと、倍率が上がります。

ズームを飛ばして、酛へ進む

拡大 1 / 4

  1. 約5mm米1粒
  2. 約1mm心白
  3. 約0.005mmでんぷんの粒
  4. 約0.003mm麹菌の糸

5〜18日目酛（酒母）

酵母を育てる「酒母」を、小さなタンクでつくります。麹・蒸した米・水に酵母を合わせて、温度を少しずつ上げて、また下げます。約2週間、静かに待つ仕事です。

かかる日数
約14日
温度
8〜15℃

19〜22日目三段仕込み

酒母に、蒸した米・麹・水を、3回に分けて加えます。初添（はつぞえ）、1日休む「踊り」、仲添（なかぞえ）、留添（とめぞえ）。少しずつ足すと、酵母が弱らずに増えます。

かかる日数
4日間（3回に分ける）
温度
8〜10℃

23〜42日目醪（発酵）

醪（もろみ）は、約20日かけて発酵します。毎朝、タンクの温度を測って、帳面に書きます。1℃ずれたら、冷やし方を変えます。この頁の左の線は、この帳面の数字をなぞったものです。

かかる日数
約20日
温度
8〜13℃（低めを保つ）

43〜45日目搾り

醪を袋に入れて、酒と粕に分けます。最初に出る酒、中ほど、最後と、味が少しずつ変わります。どこを瓶に詰めるかは、舌で決めます。

かかる日数
約3日
蔵の温度
約5℃

搾りを、手で体験する

袋を、ゆっくり押してみてください。押しているあいだだけ、酒がしたたります。（パソコンはマウスを押したまま、キーボードはスペースキーを押したまま）

0 滴　約 0 ml / 小さな盃1杯（10ml）

一升瓶（1.8L）なら、この盃のおよそ180杯ぶん。約3万6千滴です。

46〜48日目火入れ・瓶詰め

酒を65℃ほどに温めて、菌と酵素の働きを止め、瓶に詰めます。ここまで、およそ48日。米を洗った日の水の冷たさを、帳面の最初の行が覚えています。

火入れ
約65℃（短い時間）
